# ACM_2026
D1 contains historical data from 1992–2017, while D2 covers 2001–2010. D3 is an imputed version with missing values estimated to improve completeness. Each dataset is tested with Moirai, Chronos 2, Linear Regression, LightGBM, Random Forest, LSTM, fine-tuned Moirai/Chronos, Persistence, and XGBoost.
